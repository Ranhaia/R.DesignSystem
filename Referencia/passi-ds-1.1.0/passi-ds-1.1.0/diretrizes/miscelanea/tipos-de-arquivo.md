# Tipos de arquivo

Miscelânea do PASSI DS 1.1.0 · página "Tipos de arquivo" no arquivo Figma.

Ícones de formato para anexos, downloads e listas de arquivos. Cada formato tem sigla, símbolo e cor, para ser reconhecido mesmo por quem não distingue cores.

## Ícone de arquivo

Ícone de arquivo · mostra o formato de um arquivo para baixar ou anexar. Sigla, símbolo e cor juntos, para não depender só da cor. Para formatos fora da lista, use Genérico e troque a sigla.

- Variantes · Formato: PDF, DOC, XLS, PPT, TXT, CSV, MD, PNG, JPG, SVG, GIF, MP4, MP3, WAV, ZIP, HTML, CSS, JS, JSON, Genérico

## Item de arquivo

Item de arquivo · linha de anexo com formato, nome, tamanho e botão de baixar.

## Como usar

### Formatos

Agrupados por tipo de conteúdo.

### Em uso

Lista de anexos de um projeto. O Item de arquivo junta o formato, o nome, o tamanho e o botão de baixar.

## Faça

- Use o formato real do arquivo que a pessoa vai baixar
- Mostre nome e tamanho ao lado do ícone
- Para formatos fora da lista, use Genérico e troque a sigla

## NÃO faça

- Diferenciar formatos só pela cor
- Siglas com mais de 4 letras
- Trocar o ícone do formato pelo logo de um programa
