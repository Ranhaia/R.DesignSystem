# Bandeiras

Miscelânea do PASSI DS 1.1.0 · página "Bandeiras" no arquivo Figma.

Bandeiras simplificadas para seletores de país, códigos de telefone e endereços. Todas na proporção 3:2 e sem brasões, para ficarem legíveis em tamanho pequeno.

## Bandeira

Bandeira · versões simplificadas para interfaces pequenas, todas em 3:2 e sem brasões ou escritos. Para uso oficial, use os arquivos publicados pelos governos.

- Variantes · País: Brasil, Argentina, Bolívia, Chile, Colômbia, Paraguai, Peru, Uruguai, Venezuela, Estados Unidos, México, Alemanha, Áustria, Bélgica, Dinamarca, Espanha, Finlândia, França, Grécia, Irlanda, Itália, Noruega, Países Baixos, Polônia, Portugal, Reino Unido, Rússia, Suécia, Suíça, Ucrânia, União Europeia, China, Índia, Japão, Nigéria

## Como usar

### Aviso

### Bandeiras

Agrupadas por região, em ordem alfabética.

### Em uso

Campo de telefone com código do país e lista para escolher o país de entrega.

## Faça

- Mostre sempre o nome do país junto da bandeira
- Coloque o país mais provável no topo ou já selecionado
- Use os arquivos oficiais em qualquer uso fora de telas

## NÃO faça

- Usar bandeira para representar idioma (português não é só do Brasil)
- Ampliar estas versões simplificadas para tamanhos grandes
- Mostrar bandeira sozinha, sem texto, em listas de escolha
