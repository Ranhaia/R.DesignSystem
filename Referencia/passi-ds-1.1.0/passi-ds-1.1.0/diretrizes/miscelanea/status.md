# Status

Miscelânea do PASSI DS 1.1.0 · página "Status" no arquivo Figma.

Peças para mostrar estado: o ponto de presença de uma pessoa e o indicador de status de um item. Em todos, o estado é visto pela forma e pelo texto, não só pela cor.

## Ponto de status

Ponto de status · presença de uma pessoa (online, ausente, ocupado, offline). Cada estado tem forma própria, além da cor. Vai no canto inferior direito do avatar.

- Variantes · Status: Online, Ausente, Ocupado, Offline
- Variantes · Tamanho: P, M, G

## Indicador de status

Indicador de status · estado de um item (projeto, tarefa, pedido) em listas e tabelas. Marcador com forma própria + texto, para não depender só da cor.

- Variantes · Status: Ativo, Em andamento, Pendente, Pausado, Concluído, Erro, Rascunho, Arquivado

## Como usar

### Ponto de status

Quatro estados de presença em três tamanhos. A borda clara separa o ponto do avatar.

### Indicador de status

Oito estados para itens. Use o mesmo nome do status em todo o produto.

### Em uso

Equipe com presença e lista de projetos com status.

## Faça

- Junte cor com forma ou texto: o status não pode depender só da cor
- Use os mesmos nomes de status em todo o produto
- Ponha o ponto de presença no canto inferior direito do avatar

## NÃO faça

- Inventar cores novas para cada status
- Ponto de status sem legenda quando ele é a informação principal
- Mais de oito status diferentes no mesmo fluxo
