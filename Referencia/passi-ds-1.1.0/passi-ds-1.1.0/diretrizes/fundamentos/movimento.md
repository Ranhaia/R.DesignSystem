# Movimento

Fundamento do PASSI DS 1.1.0 · página "Movimento" no arquivo Figma.

O movimento explica o que está acontecendo: de onde algo veio e para onde foi. Animações curtas e consistentes deixam a interface mais clara sem chamar atenção para si mesmas.

## Como usar

### Durações

Quanto maior o elemento ou a distância percorrida, maior a duração.

### Curvas

A curva define a aceleração. Entrada começa rápido e termina suave; saída começa suave e acelera.

### Transições comuns

Combinações de duração e curva para os componentes do sistema.

## Faça

- Use movimento para explicar mudanças, não para enfeitar.
- Respeite a preferência de reduzir movimento do sistema operacional: use o modo Reduzido da coleção Movimento.
- Mantenha a maioria das animações abaixo de 300 ms.

## NÃO faça

- Animações que atrasam a pessoa, como esperar a tela terminar de mexer para clicar.
- Movimentos diferentes para a mesma ação em telas diferentes.
- Elementos piscando ou girando sem parar.
