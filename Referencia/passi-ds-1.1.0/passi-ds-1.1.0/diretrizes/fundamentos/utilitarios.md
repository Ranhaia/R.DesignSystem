# Utilitários

Fundamento do PASSI DS 1.1.0 · página "Utilitários" no arquivo Figma.

Peças de apoio para documentar e entregar telas ao time de desenvolvimento: marcadores numerados, notas de comportamento, medidas e o cabeçalho de cada tela. Elas não aparecem no produto, só no arquivo de trabalho.

## Marcador numérico

Marcador numérico · número para ligar um ponto da tela a uma nota de anotação.

- Variantes · Cor: Marca, Atenção, Erro

## Nota de anotação

Nota de anotação · explica comportamentos, regras e dúvidas ao lado das telas. Ligue cada nota a um ponto da tela com o mesmo número.

- Variantes · Tipo: Comportamento, Atenção, Pergunta

## Medida

Medida · mostra distâncias e tamanhos nas telas entregues ao desenvolvimento. Estique até o tamanho medido e escreva o valor (de preferência o nome do espaço, como espaco/6).

- Variantes · Orientação: Horizontal, Vertical

## Cabeçalho de entrega

Cabeçalho de entrega · fica acima de cada tela entregue ao desenvolvimento: fluxo, nome da tela, status, responsável e data.

## Anotação de acessibilidade

Etiquetas para anotar acessibilidade em telas: ordem de foco, títulos, regiões, rótulos, texto alternativo, anúncios do leitor de tela e elementos decorativos. Coloque ao lado do elemento anotado. Só para documentação: não vai para o produto.

- Variantes · Tipo: Ordem de foco, Título, Região, Rótulo, Texto alternativo, Anúncio, Decorativo

## Como usar

### Peças

### Em uso

Tela de cadastro anotada para o desenvolvimento.

### Kit de acessibilidade

Etiquetas para dizer a quem programa o que a tela não mostra: a ordem do foco, os títulos, as regiões, os rótulos, o texto das imagens e o que o leitor de tela anuncia. Anotar antes evita que a IA ou a pessoa que programa invente.
