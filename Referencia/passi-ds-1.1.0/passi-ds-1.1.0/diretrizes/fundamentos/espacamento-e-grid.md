# Espaçamento e grid

Fundamento do PASSI DS 1.1.0 · página "Espaçamento e grid" no arquivo Figma.

Todo espaço do sistema é múltiplo de 4. Isso cria um ritmo visual que as pessoas sentem, mesmo sem perceber. As grades organizam a página em colunas para computador, tablet e celular.

## Como usar

### Escala de espaçamento

Use as variáveis da coleção “Espaçamento” nos preenchimentos internos e nos espaços entre elementos. No código, cada espaço vem em rem (16 px = 1 rem), para crescer quando a pessoa aumenta a fonte do navegador.

### Grades

Aplique os estilos de grade nas molduras das telas. As colunas se esticam; o espaço entre colunas e as margens são fixos.

### Larguras de referência

Computador: 1440 px (conteúdo até 1280 px). Tablet: 768 px. Celular: 375 px. Abaixo de 768 px, use a grade de celular.
