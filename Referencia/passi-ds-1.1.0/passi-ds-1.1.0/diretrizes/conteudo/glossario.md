# Glossário

Conteúdo do PASSI DS 1.1.0 · página "Glossário" no arquivo Figma.

As palavras da interface do PASSI, sempre as mesmas, em todas as telas. Um glossário evita que o mesmo gesto se chame Entrar numa tela e Login na outra.

## Termos

Use a coluna da esquerda. Quando houver dúvida, prefira a palavra que uma pessoa usaria conversando.

| Use | Evite | Observação |
|---|---|---|
| Entrar | Login, Logar, Acessar | Botão e título da tela de entrada. |
| Sair | Logout, Deslogar |  |
| Criar conta | Cadastre-se, Sign up |  |
| Esqueci minha senha | Recuperar credenciais |  |
| E-mail | Email, Endereço eletrônico | Sempre com hífen. |
| Senha | Password, Credencial |  |
| Excluir | Deletar, Apagar | Quando a coisa deixa de existir. |
| Remover | Excluir | Quando a coisa sai de uma lista, mas continua existindo. |
| Editar | Alterar, Modificar |  |
| Salvar | Gravar, Submeter |  |
| Enviar | Submeter, Submit |  |
| Baixar | Fazer download |  |
| Enviar arquivo | Upload, Fazer upload |  |
| Buscar | Pesquisar, Search | Busca como substantivo. |
| Configurações | Ajustes, Settings, Preferências |  |
| Painel | Dashboard |  |
| Notificações | Alertas | Alerta é o componente de mensagem na página. |
| Você | O usuário, O cliente | Fale com a pessoa. |
| IA | A.I., Inteligência Artificial com iniciais maiúsculas | Por extenso: inteligência artificial. |

## Faça

- Consulte o glossário antes de criar um texto novo.
- Proponha um termo novo quando surgir uma palavra que se repete.
- Use o mesmo termo no botão, no título e na mensagem de confirmação.

## NÃO faça

- Misturar inglês e português no mesmo produto.
- Sinônimos para o mesmo gesto em telas diferentes.
- Siglas sem explicar na primeira vez.
